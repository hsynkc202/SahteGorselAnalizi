# Sahte görsel tespit yazılımı
Bu projede klasik algoritmalar ve yapay zeka algoritmaları kullanılarak bir görselin gerçek mi manipüle edilmiş mi olduğunu tespit ediliyor
Çalıştırabilmek için gerekli modellerin mevcut olması gerekmektedir

# İndirme
pip install -r requirements.txt

# Çalıştırma 
python -m streamlite run app.py
